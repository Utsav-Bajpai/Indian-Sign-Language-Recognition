# Indian-Sign-Language-Recognition-Initialization
In India, there are millions of people with hearing and speech disabilities that depend on Indian Sign Language (ISL) to communicate. Until now, there has not been a public available solution to the deaf-hearing community communication barrier. This study has developed the first interdisciplinary approach with the best of our knowledge to the development of a real-time ISL communication system. We fused MediaPipe Hands with a deep learning based recognition system to develop a real-time ISL communication system. We are able to improve real-time communications with a system that accurately and quickly detects ISL alphabet gestures. We created a system that utilizes standard webcam input to extract 21 3D hand landmarks per hand. We were able to create a 126-dimensional feature vector comprised of both hands per frame. This self-constructed compact representation of the hand landmarks leads to a more efficient system than the raw pixel input array. We constructed a multi layered feed-forward neural network to perform 26-class ISL alphabet classification. We also employed other standard techniques to improve the performance of the system such as batch normalization and dropout regularization. Our solution demonstrates that ISL representation can be performed accurately and that the system can be used as assistive technology. Our development not only demonstrates the potential of MediaPipe and deep learning technology integration, but also that efficient sign language recognition is a possibility. This system is aimed to be a low-cost, open-source option to be used as a foundation for future developments on ISL recognition and to advance the recognition systems to a sentence level. Index Terms—Indian Sign Language, MediaPipe Hands, gesture recognition, hand landmark detection, deep learning, realtime classification, feedforward neural network, accessibility technology
